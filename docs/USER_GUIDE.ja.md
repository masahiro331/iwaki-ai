# Iwaki AI - 利用ガイド

**信長の野望 真戦** の Discord サーバー向け Bot です。
チャンネルの会話を AI が要約してくれたり、いずれは同盟運営に
役立つコマンドを増やしていく予定です。

> 開発者・運用者向けのドキュメントは [README.md](../README.md) を参照してください。

## いまできること

| コマンド | 内容 |
|---|---|
| `/summarize` | チャンネルの直近の会話を AI が要約して投稿します |

## `/summarize` の使い方

Discord で `/` を打って `summarize` を選ぶか、直接タイプします。

```
/summarize
```

これだけで **実行した channel の直近 24 時間** が要約されます。

期間を変えたいときは `since` オプションを付けます。

```
/summarize since:3h          ← 直近 3 時間
/summarize since:24h         ← 直近 24 時間（デフォルトと同じ）
/summarize since:72h         ← 直近 3 日
/summarize since:168h        ← 直近 1 週間（最大）
```

時間の単位は `h`（時間）と `m`（分）を組み合わせられます。`since:90m` で「直近 90 分」など。

要約は数十秒かかります。Discord の「考え中…」表示が出ている間お待ちください。

## `/summarize` の制限事項

| やりたいこと | 可否 |
|---|---|
| channel の直近の会話を要約 | ✅ |
| スレッド内の会話を要約 | ⚠️ スレッド ID を直接渡さないと無理（通常運用では未対応） |
| 複数 channel を横断して要約 | ❌ |
| 1 週間より前の会話を要約 | ❌（期間上限 168 時間） |
| Bot の投稿を含めて要約 | ❌（Bot の発言は除外されます） |
| 別 channel に要約を投げる | ❌（実行した channel に投稿します） |
| 画像・動画・添付ファイルを理解する | ❌（テキストのみ。画像対応は今後） |

## トラブルシュート

### コマンド `/summarize` が候補に出てこない

- Discord クライアントをリロードしてみてください（`Cmd+R` / `Ctrl+R`）
- Bot がそのサーバーに参加していない可能性があります → サーバー管理者に確認
- Bot にそのサーバーで `slash command` を使う権限がない可能性があります

### 「Bot が応答していません」と表示される

- Bot プロセスが停止している可能性 → 運用者に連絡してください
- 一時的な API 障害でリトライ中の可能性 → 数分後にもう一度試してください

### 「failed: ...」と表示される

- AI API の一時的な過負荷（503）→ 数分後に再実行
- 期間が長すぎて入力が制限を超えた → `since` を短くして再試行
- 該当期間に会話がなかった → 「(no messages in the given window)」と表示されます

### Bot が channel を見えていない

- プライベートチャンネルの場合、Bot に明示的に **`チャンネルを見る`** と **`メッセージ履歴を読む`** 権限が必要です
- サーバー管理者に Bot ロールへの権限付与を依頼してください

## プライバシーとデータの取り扱い

この Bot を安心して使うために、内部で何が起きているか共有します。

### 何が起きるか

1. `/summarize` を実行すると、Bot が指定期間の **メッセージ本文・投稿者名・投稿時刻** を Discord API 経由で取得します
2. 取得したメッセージは **Google の Gemini API** に送信され、要約が生成されます
3. 生成された要約が Discord channel に投稿されます

### 何が保存されるか

- **Bot のサーバー上**: メッセージは保存されません。要約処理が終わると破棄されます
- **Bot のログ**: 実行者名、channel ID、件数、入力文字数、応答時間 などのメタ情報のみ。**メッセージ本文はログに残しません**
- **Google (Gemini)**: Google の API 利用規約に従います。Free tier の場合、**入力データがモデル改善に使われる可能性があります**（Paid tier では使われません）

### 機密情報の取り扱い

- 同盟戦の作戦・パスワード・個人情報などを含むメッセージがある期間で `/summarize` を実行すると、その内容が Google API に送信されます
- 特に機密性が高い channel での利用は避けてください
- 一度送信した内容は取り消せません
